Demon Queen RPG

This project is done when I'm bored during a class. Out of boredom, I got the feeling of creating a game file through using a Java language using Eclipse IDE. It has its own UI and window where it shows the castle of the enemy boss fight you're gonna encounter, which in the name suggests, is the Demon Queen herself. I just took a random Demon Queen image online and put it as her appearance for the game. The concept of the game is to guess a number from 1 to 1,000,000 for the reason that you need to find her "weakspot". The closer you are to the weakspot, the higher damage you'll deal to the Demon Queen . On paper, I'm thinking of adding additional features like actually making the Demon Queen attack, an option for the player to attack, defend, or use skills, and HP for the player and how they would be defeated. Currently, the latest version I made only includes the window, images, damage dealing of the player to the Demon Queen, and Demon Queen's dialogues.
